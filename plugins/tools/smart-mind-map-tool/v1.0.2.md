# Smart Mind Map Tool v1.0.2 Release Notes

## Overview

- **Read `JSONResponse` results from `generate_chat_completion`**: backends such as OpenAI-compatible connections return a `JSONResponse` instead of a dict, which failed with `argument of type 'JSONResponse' is not iterable` (#117). The body is now decoded as JSON before the `choices` are read.

## Compatibility

- Behavior is unchanged for backends that already return a dict. No new Valves, no breaking changes.

## Upgrade Notes

Update or reinstall the plugin.
